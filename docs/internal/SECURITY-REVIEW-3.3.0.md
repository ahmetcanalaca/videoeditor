# Güvenlik incelemesi 3.3.0 · Security review 3.3.0

*12 Kasım 2026 · 12 November 2026.* Kapsam / scope: 3.3.0 masaüstü + 4.2.0 web sürümünün değişiklikleri (3.2.0 / 4.1.0'a göre): **Foundry Local entegrasyonu** (komut satırı, `daemon.json`, no-auth loopback sunucusu, istemle araç çağırma ayrıştırıcısı, arayüz), web sürümünden **Yerel AI yardımcısının kaldırılması**, GitHub Actions iş akışları, tedarik zinciri ve uçtan uca ürün yüzeyi (Electron sertleştirmesi, IPC, FFmpeg komutları, proje dosyası, kurulum dosyası, gizli bilgi saklama) ve "belgelerdeki iddialar koda uyuyor mu". Yöntem / method: **bağımsız statik inceleme** (ayrı bir inceleme ajanı; çalıştırmadan, salt okunur) + benim çalıştırdığım dinamik testler + **gerçek Foundry Local 0.14 ile canlı kontroller** (aşağıda). Önceki incelemeler (3.0.0: 17 bulgu, 3.1.0: 5 not, 3.2.0: 6 düşük bulgu) bilinen kabul edildi. · *Earlier reviews were taken as known.*

**Sonuç: kritik veya yüksek bulgu yok.** 1 orta ve 3 düşük bulgu çıktı; **hepsi düzeltildi**. **Ek notlar ve karşılıkları · further notes:** LM Studio "Enable CORS" ipucu her web sitesine izin verdiğini söylemiyordu → web ayarlarındaki metin (TR/EN) artık "mümkünse yalnızca bu siteye izin verin (Ollama `OLLAMA_ORIGINS`); LM Studio'nunki her siteye izin verir" diyor · yerel `web/_site` (eski yardımcı zip'i) silindi · `web/tests/lna.test.js` yerel model sunucusu için uyarlanıp geri eklendi (Local Network Access: ret / izin / başka sayfanın yazdığı ayarlar) · sayfanın depoladığı eski yardımcı eşleştirme anahtarı (`ve.web.ai.helper.v1`) asistan başlarken siliniyor (testli) · eski `#local-ai=…` bağlantısı artık hiçbir şey yapmıyor (testli).

**Kabul edilenler · accepted:** (1) test kancaları (`VE_TEST_FL_*`, `VE_TEST_OPEN_LOG`) paketli sürümde de var, yalnızca `VE_TEST_MODE=1` ile çalışır; ortam değişkenini ayarlayan zaten aynı kullanıcıdır ve `RunAsNode` fuse'u kapalı (kancalar paketlenmiş uygulamanın arayüz testleri için gerekli) · (2) `foundry.exe` takma adı kullanıcının kendi klasöründe: aynı kullanıcıdan gelen bir yer değiştirme, uygulamanın kendi dosyalarını değiştirebilen aynı kullanıcıdan farksızdır; başka kullanıcıdan vektör yok · (3) Foundry Local'in sunucusu anahtar istemez (Foundry Local'in tasarımı): arayüzde ve belgelerde yazıyor; paylaşılan bilgisayarda anahtarlı yerleşik model önerilir · (4) uygulama başlarken Foundry Local seçiliyse `foundry cache list` çalışır (aynı kullanıcı sınırı içinde; yerel, ağ yok). · *Test hooks ship in the package but need `VE_TEST_MODE=1` and the same user; a same-user planted alias is no different from a same-user edit of the app; the key-less server is Foundry Local's design (documented, shown in the UI); `foundry cache list` runs at start when Foundry Local is the chosen provider (local, no network).*
