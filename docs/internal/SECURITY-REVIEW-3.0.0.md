# Güvenlik incelemesi 3.0.0 · Security review 3.0.0

*10 Kasım 2026 · 10 November 2026.* Yöntem / method: bağımsız statik inceleme (tehdit modeli: "sayfadaki betik en az güvenilen bölümdür") + `npm audit`, kilit dosyası, fuse, paket, sır ve ağ denetimleri. Sonuç: uzaktan, kimlik doğrulamasız bir saldırı yolu yok; 1–3 numaralı bulgular, sayfada zaten bir betik çalışırsa ikinci aşama olarak devreye girerdi. **13 bulgunun hepsi düzeltildi ve testlerle doğrulandı.** · *Result: no remote, unauthenticated attack path; findings 1–3 were second-stage (a script already running in the page). All 13 findings are fixed and covered by tests.*

**Bilinen kalıntılar (bilerek) · Known residuals (deliberate):** `GrantFileProtocolExtraPrivileges` açık (arayüz `file://` ile yüklenir) · on (the UI loads through `file://`); ffmpeg/llama ikililerinin çalışma anı bütünlük denetimi yok (SHA-256 paketleme sırasında sabitlenir) · no run-time integrity check of the bundled binaries (pinned at packaging); `shareNames` varsayılanı açık (yalnızca bulut sağlayıcılarda önemli; ayarlardan kapatılır) · on by default (matters for cloud providers only); uygulama imzasız · the app and installer are not code-signed; `VE_TEST_MODE=1` ortam değişkenini ayarlayabilen biri test kancalarını açabilir (aynı kullanıcı; kapsam dışı) · whoever can set `VE_TEST_MODE=1` can switch the test hooks on (same user; out of scope); `--selftest-out` komut satırından yerel bir `.json` dosyasının üzerine yazabilir (komut satırını denetleyen zaten kod çalıştırabilir) · `--selftest-out` can overwrite a local `.json` file from the command line (whoever controls the command line can already run code); kurulum klasörü kullanıcı klasörünün dışındaysa ve sessiz kurulumda (`/D=`) uyarı sorulmaz; klasörün izinleri üst klasörden devralınır (BT kurulumu kendi kararıdır) · for a silent install (`/D=`) outside the profile nothing is asked and the folder inherits its parent's permissions (the deployer's decision).

## İkinci tur · Second pass (düzeltmelerin bağımsız yeniden incelemesi · independent re-review of the fixes)

*Yöntem / method:* 13 düzeltmenin her biri için kodda "gerçekten etkili ve aşılamaz mı" denetimi (yol biçimleri `\\?\`, `\\.\`, UNC, kısa adlar, akışlar, junction, `C:foo`; IPC'nin sırayla/yanlış türlerle çağrılması; `__proto__` anahtarları) + düzeltme kodunun kendi zayıflıkları + kurulum/paketleme. **Sonuç: 13 düzeltmenin hiçbiri aşılamadı ("fixed-and-sound"); 3 yeni düşük bulgu çıktı; bir de "WebRTC çalışma anında doğrulanmadı" notu vardı — deneyle doğruladım: gerçekti.** Hepsi düzeltildi. · *Result: none of the 13 fixes could be bypassed; 3 new low findings; plus a note that WebRTC "was not verified at run time" - I verified it by experiment: it was real.* All fixed.
